# GitHub 新手使用说明

仓库地址：[bluebird05213-crypto/mycode](https://github.com/bluebird05213-crypto/mycode)

## 你需要认识的 4 个概念

- `main`：稳定版本，平时不要直接在这里试验大改动。
- `dev`：开发版本，Codex 后续功能通常先在这里修改和测试。
- `commit`：一次可以回看的本地版本记录。
- `tag`：给重要版本起名字，例如 `v0.1.0`。

## 在 GitHub 网页上查看版本

进入仓库后：

1. 点击左上角分支下拉框，可以切换 `main` 和 `dev`。
2. 点击页面上的分支或提交记录，可以查看每次改了什么。
3. 点击 `Releases` 或标签列表，可以找到 `v0.1.0` 等稳定版本。

## 出问题时如何回到旧版本

优先告诉 Codex：

```text
请把项目恢复到 v0.1.0，先检查差异，不要直接删除我的本地题库数据。
```

代码版本可以恢复，但浏览器里的题库和学习记录属于本机数据，不会被 Git 版本自动恢复。两者是分开的。

## 后续 Codex 的默认工作流

每次功能修改会遵循：

```text
读取当前版本 → 修改代码 → pnpm build → 浏览器回归 → 创建 commit → 推送 dev
                                             ↓
                                      稳定后更新 main 和版本标签
```

如果修改涉及数据格式，必须同时增加迁移逻辑和回退说明。个人 PDF、浏览器数据、密钥和本地缓存不会推送到仓库。
